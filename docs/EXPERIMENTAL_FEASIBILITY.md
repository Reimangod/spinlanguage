# 実験へ移すときの制御・計測・未知量

本MVPはシミュレーションであり、実測データはない。YIGへPMA/VCMAが備わると仮定していない。

| 種類 | MVPでの扱い | 実機の対応 | 校正/障害 |

| 入力 |固定4RF I/Q、5 microtesla、200 MHz | RF搬送波+IQ変調+CPWアンテナ | インピーダンス、実際のB_RF、波数選択 |

幅800 micrometreの周期計算領域は、直線薄膜の端反射や曲がった実リングと一致しない。8本のコイルをその寸法へ集積する工学設計は未検証である。原著のmmスケールPCBコイル実験は制御機構の根拠であり、今回のサイズを保証しない。実装可能性を優先する次の段階では、より大きいYIG素子と実測transfer matrixから縮約を校正するのが最短である。

最短の実験手順は、少数アンテナのS21(周波数/局所電流)を測る→応答行列とalpha/検出ゲインを同定する→固定RFコードで遅延応答を測る→モデル上のWeightを実機へ設定する→validation相当の実データで有限差分/SPSA微調整する、の順である。まずDelayed Recallを測り、成立してから文字予測を接続する。

DC制御の推定消費電力は、抵抗R_aが測れれば `sum R_a I_a²`。今回R、ADC/LNA/RF source電力が不明なので、数値的なJ/tokenやGPUとのエネルギー優位を算出しない。Weight変更回数・I²・センサ数は資源の代理値として扱う。GPUが速いことと物理回路のmeasurement/energyが小さいことは別である。
