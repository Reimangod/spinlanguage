# Architecture Decision Record - 2026-10-14

要求仕様 `codex_magnonic_lm_mvp_prompt.md` を全文読んでから、本チャット専用に実装した。他チャットの科学プロトコル・データ・コードを流用していない。既存Python環境は基礎ライブラリの読出しだけに利用する。

材料はYIG。垂直飽和磁場350 mT、32個の空間自由度、最低厚みモードのdipole-exchange分散を持つ複素振幅を状態とする。主ソルバーは独自PyTorch縮約モデル1種類。回転座標系で解析的な線形伝搬と局所位相・弱いKerr項・RF駆動を対称分割する。周期境界は閉じた計算領域のMVP仮定であり、有限矩形素子の忠実な形状再現ではない。

入力は固定の文字→4本のRF I/Qコード、振幅上限5 microtesla、帯域200 MHz。学習Embeddingはない。8本の局所DC電流をtanhで±400 mAに制限する。Gaussianの空間応答は要校正で、重なりを正規化して±2 mT以内にする。YIG自身にPMA/VCMAを書き込むことはしない。減衰・交換・Msは学習しない。

観測は4本のアンテナ平均のI/Q信号、帯域100 MHz、1文字につき2時点、計16 real features。Readoutは線形+softmaxだけ。全セル状態、文字ID、過去文字履歴をReadoutに直接渡さない。入力符号表は固定で両物理モデル共通。検出出力は未校正の正規化電圧で、SI電圧やエネルギー性能を主張しない。

内部学習は32文字のBPTT+Adam。磁場→位相→伝搬→観測→CEの有限差分照合を行う。微分可能な少数制御なので、勾配不要の数千回の候補シミュレーションより効率的と考えるが、実機ではモデル誤差があるため実測有限差分/SPSAによる微調整を検討する。外側探索は入力ポート配置2候補の等予算比較。MLP・Attentionや巨大Transformerは主モデルへ追加しない。

合成評価は8クラスDelayed Recall。これはSelective Copyingと異なり、長期記憶の限定的検査である。自然言語はTiny Shakespeare全コーパスの90/5/5連続分割。32文字の独立窓で比較し、状態リセットとteacher forcingを明示する。固定/内部学習/記憶無効化には同じ線形Readoutを用い、GRUは小さいデジタル比較器として別のparameter budgetを報告する。

既存のSpinTorchは原著・公式solverを確認したが、長い文字系列に対する全LLGの大きな計算量と旧版依存のため今回の主ソルバーとして採用しない。MuMax3/NeuralMag/magnum.npの統合、MTJ輸送、イオン輸送、3D連成は追加しない。縮約の最終的な実機妥当性には独立LLG/実測校正が必要である。

初版4 substepsの入力/検出積分に大きな刻み依存があったため、中点入力・台形観測へ修正し8 substepsを採用。32文字試験では64 substepsとの差0.936%だった。これはシミュレータの内部整合性であり、物理近似の真実性を証明しない。

予算と停止条件は `configs/protocol_v1.json` に登録。A100 1台×2ジョブの独立worker方式を用い、研究全体の更新回数はworker間で分割する。共有ストレージ満杯のため、今回だけのRAM領域とMacへの出力転送を使う。
